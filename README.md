# Olist E-commerce Sales Analysis using SQL

## Project Overview
This project uses SQL and MySQL to practice analyzing e-commerce order data from the Olist Brazilian E-Commerce Public Dataset.

The project contains 20 business-focused SQL questions covering order analysis, customer information, order trends, and product sales.

## Dataset
- **Dataset:** Brazilian E-Commerce Public Dataset by Olist
- **Source:** [Kaggle – Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Practiced
- SELECT and DISTINCT
- WHERE and filtering
- ORDER BY and LIMIT
- COUNT and SUM
- GROUP BY and HAVING
- Date filtering and YEAR()
- DATE_FORMAT()
- INNER JOIN and LEFT JOIN
- NULL handling
- Business-focused SQL queries

## Business Questions Explored
1. Display the first 10 orders.
2. Find delivered orders.
3. Identify the 10 most recent orders.
4. Count total orders.
5. Identify unique order statuses.
6. Count orders by status.
7. Find statuses with more than 100 orders.
8. Review orders placed during 2018.
9. Inspect canceled orders.
10. Count delivered orders.
11. Summarize orders by status.
12. Rank order statuses by order count.
13. Identify the 10 oldest orders.
14. Count orders by year.
15. Display the five most recent orders.
16. Display orders with customer IDs and cities.
17. Identify orders without matching customer records.
18. Calculate sales by product category.
19. Identify the five highest-spending customers.
20. Count orders by month.

## Project Learning
This project helped me practice SQL fundamentals and apply queries to common e-commerce business questions. It also gave me practice working with multiple tables and exploring customer, order, and sales data.

## Note
Some join-based analyses did not return matching records in the imported tables during this practice. The related table relationships and imported data may require further validation before reliable sales findings can be reported.
